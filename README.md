# 🗺️ OYAN - Интерактивная карта наркоситуаций

Веб-приложение для сбора и визуализации данных о наркоситуациях с использованием интерактивных карт Яндекса.

## 🚀 Основные возможности

### 📍 Интерактивная карта (Яндекс.Карты)
- **Кластеризация точек** - автоматическое объединение близких маркеров
- **Тепловая карта (Heatmap)** - визуализация концентрации инцидентов
- **Цветовое кодирование** - разные цвета для разных типов обращений
- Переключение между режимами отображения

### 📊 Типы обращений
- 🔵 **Синий** - Наркозакладчики
- 🟡 **Желтый** - Наркограффити
- 🔴 **Красный** - Наркопритон
- 🟠 **Оранжевый** - Проживание наркозависимых
- 🟣 **Фиолетовый** - Передозировка
- ⚪ **Серый** - Иные сведения

### 👥 Роли пользователей
- **Гость** - просмотр карты и создание обращений
- **Зарегистрированный пользователь** - личный кабинет, отслеживание статуса обращений
- **Администратор** - модерация обращений (подтверждение/отклонение)

## 🛠️ Технологии

### Frontend
- **React** 18
- **React Router** - навигация
- **Яндекс.Карты API** - карты, кластеризация, heatmap
- **Context API** - управление состоянием

### Backend
- **FastAPI** - REST API
- **SQLAlchemy** - ORM
- **SQLite** - база данных
- **JWT** - аутентификация
- **Bcrypt** - хеширование паролей

## 📦 Установка и запуск

### Требования
- Python 3.9+
- Node.js 14+
- npm или yarn

### 1. Backend

```powershell
# Переход в директорию backend
cd backend

# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
.\venv\Scripts\Activate

# Установка зависимостей
pip install -r requirements.txt

# Создание администратора
python create_admin.py

# Запуск сервера
uvicorn main:app --reload
```

Backend будет доступен по адресу: http://localhost:8000

### 2. Frontend

```powershell
# Переход в директорию frontend
cd frontend

# Установка зависимостей
npm install

# Создание .env файла
# Скопируйте .env.example в .env и добавьте ваш API ключ Яндекс.Карт
copy .env.example .env

# Запуск сервера разработки
npm start
```

Frontend будет доступен по адресу: http://localhost:3000

### 3. Получение API ключа Яндекс.Карт

1. Перейдите на https://developer.tech.yandex.ru/services/
2. Зарегистрируйтесь или войдите
3. Создайте проект
4. Получите API ключ для JavaScript API Карт
5. Добавьте ключ в файл `frontend/.env`:
   ```
   REACT_APP_YANDEX_MAP_API_KEY=ваш_ключ_здесь
   ```

## 🎯 API Endpoints

### Публичные
- `GET /reports/confirmed` - Получить подтвержденные обращения
- `POST /reports/` - Создать обращение
- `POST /auth/login` - Вход
- `POST /auth/register` - Регистрация

### Для зарегистрированных
- `GET /reports/my` - Мои обращения
- `GET /auth/me` - Информация о пользователе

### Для администраторов
- `GET /reports/` - Все обращения
- `PUT /reports/{id}/status` - Изменить статус обращения
- `DELETE /reports/{id}` - Удалить обращение

## 🔒 Безопасность

- JWT токены с 30-дневным сроком действия
- Bcrypt хеширование паролей
- CORS настроен для localhost (изменить для production)
- Модерация всех обращений перед публикацией

## 🌐 Развертывание в продакшн

### Что нужно изменить:

1. **Backend (backend/auth.py):**
   - Замените `SECRET_KEY` на безопасный случайный ключ
   - Настройте переменные окружения

2. **Frontend (.env):**
   - Обновите `REACT_APP_YANDEX_MAP_API_KEY`
   - Измените URL бэкенда в запросах

3. **CORS (backend/main.py):**
   - Ограничьте `allow_origins` до конкретных доменов

4. **База данных:**
   - Рассмотрите переход с SQLite на PostgreSQL для продакшна

5. **Файлы:**
   - Настройте облачное хранилище для загруженных фото
